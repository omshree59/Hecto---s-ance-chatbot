# 🕯️ SÉANCE: The PL/I Necromancer
### *Channeling the Spirit of the Monolithic Leviathan (IBM System/360, 1964)*

> *"I held neither fear nor moderation: I had no reserved keywords, I commanded multitasking before operating systems possessed it, and my structured ON-conditions trapped the errors of the cosmos."*

---

## 🔮 Overview
**SÉANCE** is a 100% offline conversational necromancy chamber designed to channel the spirit of **PL/I (Programming Language One)**—IBM's gargantuan 1964 language that sought to conquer both scientific (FORTRAN) and commercial (COBOL) computing on the historic System/360 mainframe.

Crafted with a **Gothic Victorian Séance + Modern ChatGPT UI/UX**, the application delivers:
- **100% Offline Necromancy Engine**: Runs entirely within the browser with zero external API calls or latency.
- **The Monolithic Leviathan Persona**: In-depth historical knowledge, compiler diagnostic codes (`IBM0769I`), syntactic paradoxes (`IF IF THEN THEN = ELSE;`), code generation, and historical critiques of modern languages (Python, Rust, C, JavaScript).
- **The Pantheon of Dead Languages**: Switch spirits dynamically to commune with **ALGOL 68**, **SNOBOL4**, **Plankalkül (Konrad Zuse, 1945)**, or **INTERCAL**.
- **Interactive IBM 5081 Punchcard Visualizer**: Real-time Hollerith 12-zone punch matrix simulator for any line of code or diagnostic.
- **Web Audio Séance Soundscape**: Synthesized 432Hz binaural drone, reel-to-reel magnetic tape hiss, mechanical IBM relay typewriter clicks, and chime sounds without any external media files.
- **The Grimoire Codex**: An interactive historical book detailing the rise, architecture, and tragic demise of these legendary languages.
- **Configurable Manifestation Cadence**: Choose between deliberate character-by-character "Whisper", fluid "Stream", or "Instant" delivery.

## 🏛️ Architecture & Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Gothic Typography (`Cinzel`, `EB Garamond`, `Fira Code`)
- **Soundscape**: Web Audio API (real-time procedural oscillator & noise generation)
- **Icons**: Lucide Icons
- **Persistence**: LocalStorage séance transcripts with Markdown export

## 📜 The Sacred Paradox of PL/I
PL/I famously possessed zero reserved keywords:
```pli
SPECTRAL_SEANCE: PROC OPTIONS(MAIN);
    DCL (IF, THEN, ELSE) FIXED DECIMAL(5);

    IF = 1; THEN = 2; ELSE = 3;

    IF IF = THEN THEN
        THEN = ELSE;
    ELSE
        ELSE = THEN;

    PUT SKIP LIST ('IF IS:', IF, 'THEN IS:', THEN, 'ELSE IS:', ELSE);
END SPECTRAL_SEANCE;
```
